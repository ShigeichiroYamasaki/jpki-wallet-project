02 / PASSKEY

パスキーで本人操作を確認する

初めての方はパスキーを作成してください。次回からは指紋・顔認証などでログインできます。

iPhoneではSafariで開いてください。MetaMaskの承認後も、このSafariの画面へ戻って操作します。このサイト用のパスキーが必要です。端末を失った場合のアカウント復旧は、この試験版では未対応です。

03 / WALLET

ウォレットを接続する

iPhoneではMetaMaskアプリ、PCではウォレット拡張に接続してメッセージに署名します。送金やネットワークへの取引送信は行いません。

iPhone：MetaMaskアプリで接続を承認 → Safariのこのタブへ戻る →「ウォレットで署名」→ MetaMaskで署名を承認 → Safariへ戻る。接続にはMetaMaskの中継サービスを使用します。ページは再読み込みしないでください。アプリ切替でページが再読み込みされた場合は、パスキーでログインし直してください。
